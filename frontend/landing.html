Audits Are Point-in-Time

Code passes audit on Monday. Exploited on Tuesday. Audits verify static code, not runtime economic state across chains.

Contracts Can't See Cross-Chain

A contract on Ethereum has no way to verify if tokens were actually locked on Solana. The destination chain blindly trusts the bridge message.

Detection Takes Days, Not Seconds

Most bridge exploits are discovered hours or days after the attack. By then, attackers have laundered funds through mixers and cross-chain hops.

# The economic truth no single contract can verify
class MintLockParityInvariant:
    """
    tokens_minted_on_dest ≤ tokens_locked_on_source
    """
    window  = 600 # 10 minutes
    tolerance = 0.01 # tokens
    async def evaluate(self, event):
        minted = await self.get_mints(dest_chain)
        locked = await self.get_locks(src_chain)
        if minted > locked + self.tolerance:
            return Violation.CRITICAL(
                gap=minted - locked,
                confidence=0.95
            )
